# AI Personal Assistant and Email Summarizer

An AI-powered web application built using Python, Flask, and the Groq API. It helps users get answers to their questions and summarize emails into short, meaningful summaries.

## Features
- AI Personal Assistant
- Email Summarization
- Simple and user-friendly interface
- AI integration using Groq API

## Technologies Used
- Python
- Flask
- Groq API
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/saurabhdhule2005/AI-personal-assistant-email-summarizer.git
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key
   ```

4. Run the application:
   ```bash
   python main.py
   ```

5. Open `http://127.0.0.1:5000/` in your browser.
